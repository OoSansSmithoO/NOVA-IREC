# superNOVA IREC

Public-facing baseline for the Northern Virginia Community College superNOVA IREC sounding-rocket and payload team in Manassas, Virginia.

## Local development

```bash
npm ci
npm run dev
```

The local site runs at `http://localhost:8090/`.

## Before public launch

Replace placeholder vehicle-performance, payload-status, sponsor, and team details with approved information. Confirm the repository name before changing the GitHub Pages base path in `vite.config.ts`, sitemap, canonical URL, and 404 return link.

## Verification

```bash
npm run verify
```
